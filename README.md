# FakeLoc

基于 **LSPosed / libxposed API 101** 的虚拟定位模块。

不需要开发者选项里的「模拟位置」，也不需要 root 去改系统设置 —— 直接接管位置读取路径。
除 `android.location` 之外，还**接管目标 App 内嵌的高德 / 百度 / 腾讯定位 SDK**，
覆盖那些完全不读系统定位的 App。

## 安装

1. 安装本模块，在 LSPosed 里**启用 FakeLoc**
2. **配置作用域**（这一步决定它到底管不管用）：
   - 默认给的 `android` 与 `com.android.providers.settings` 负责反检测的全局部分，建议保留
   - 再把你想要伪造定位的 App 逐个勾上
3. 重启设备，或至少重启目标 App

> 模块的「生效范围」名单只决定**谁收到假位置**；模块本身还得在 LSPosed 作用域里。
> 两者是**与**的关系。

## 地图 Key

选点页的底图是腾讯地图，**包里不含任何 Key**，需要你自己去
[腾讯位置服务](https://lbs.qq.com) 申请一个（免费额度够个人使用），填进 App 的设置页。

申请时控制台要填的**包名与 SHA-1**，App 设置页里都显示着，各带一个复制按钮 —— 直接复制，别手抄。

> 不填 Key 也能用。选点页只是提供「选点」的便利，手动输入坐标、粘贴解析、内置城市都不受影响。

## 功能

| 功能 | 说明 |
|---|---|
| **在地图上选点** | 腾讯底图，拖图钉 / 搜地址 / 点图反查，选完统一换算成 WGS-84 |
| 坐标输入 | 纬度 / 经度，六位小数；**不做坐标系换算**，输入什么就是什么 |
| 常用坐标 | 八个内置城市，点击即设为锚点 |
| 使用真实定位 | 以当前位置为起点（需要定位权限，受 5 秒节流保护） |
| 粘贴解析 | 从剪贴板识别坐标、Google 地图链接、`geo:` URI、`?lat=&lng=` 参数 |
| 生效范围 | 全部作用域内应用，或只对勾选的那几个 |
| 信号微调 | 精度 / 海拔 / 速度 / 步行漂移；另有隐藏模拟痕迹、锁定定位源 |
| 假地址 | 城市 / 省 / 区跟着假坐标走（系统 `Geocoder` 反查），可单独关掉 |

**反检测**：抹掉 `isFromMockProvider` / `isMock` / AppOps / SettingsProvider 几处的 mock 标记，
并可**锁定原始定位源**（切断 WiFi 扫描、基站信息与原始 GNSS）—— 后者是「地图先跳到模拟点、
几秒后又跳回真实位置」的正解，它挡掉的是 App 用自研引擎自己再算一个真实位置这条路。

## 说明

- **包里不含任何厂商 SDK 的底图渲染库**，只保留腾讯一家用于选点页。高德 / 百度 / 腾讯的
  **注入通道**照常工作 —— 那是靠反射操作**目标 App 自己的**类实现的，与本包链接无关
- APK 用本项目专用密钥签名（`CN=FakeLoc`）。自己编译出来的签名不同，**两者不能互相覆盖安装**
  —— 更新请始终用本仓库的 Release。地图 Key 绑「包名 + 签名 SHA-1」，申请时以 App 设置页显示的为准
